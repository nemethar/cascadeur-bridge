# Cascadeur part of the add-on
For the addon to work properly the command files should be copied to the correct location.

1. The entire ***blender_bridge*** folder should be copied to the Cascadeur scripts folder.
By default the scripts path is ***CASCADEUR PATH\resources\scripts\python\scripts***. (So the path of the command files should be '***\scripts\blender_bridge\temp_exporter.py***')
    > On MacOS the default command path is: /CASCADEUR PATH/Cascadeur.app/Contents/MacOS/resources/scripts/python/scripts

2. Restart Cascadeur
<br>If you did everything correctly there will be a scripts > Blender Bridge menu with **Temp Batch Exporter**, **Temp Exporter** and **Temp Importer** commands in Cascadeur.
